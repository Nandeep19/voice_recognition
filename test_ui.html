4. Accuracy bench

A report card for the system. Section 3 identifies one clip and you judge the answer yourself. This runs many clips at once and scores them for you, so you get a single accuracy number instead of eyeballing results one at a time.

How to use it: add several clips whose real speaker you already know — ideally recordings you did not enroll with. Tag each one with who it should come back as, then press Run bench. Tag a clip as Not enrolled if it is someone the system has never heard, to check that it correctly refuses to guess.

Why it matters: re-run the same clips with different values in the Threshold override box at the top to find the setting that best fits your recordings. A low threshold causes false accepts (strangers wrongly matched); a high one causes false rejects (real people turned away). The scoreboard separates those two so you can see which way to move.
